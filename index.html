Grouped name → os/arch → version. Filter by name (live) and by os / arch / version — filters combine with AND. The canvas view is rendered by go-widgets/toolkit; if WebAssembly is unavailable or fails to load, the page falls back to a plain-HTML tree with the same data. A no-JS listing is always at list.html. Press ⛶ Full window (or double-click the canvas) to expand — Esc exits.
