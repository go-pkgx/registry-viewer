go-pkgx registry viewer

A filterable tree view of the go-pkgx package registry, in pure-Go wasm.

The registry is grouped name → os/arch → version. Type in the search box to filter by package name (case-insensitive, live), and use the three segmented controls to filter by os, arch and version — the filters combine with AND, and the status bar shows the live count. Click a tree row's chevron to expand or collapse it. Data is fetched from registry.json; if that fetch fails, a bundled sample is shown. Rendered entirely by go-widgets/toolkit (SearchEntry, ViewSwitcher, TreeView, VBox/HBox) onto a canvas. Press ⛶ Full window (or double-click the canvas) to expand it — Esc exits.
